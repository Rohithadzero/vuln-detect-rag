# ==========================================
# VulnDetectRAG v4.1 - Python Dependencies
# ==========================================
#
# System Requirements:
#   - Python 3.10+
#   - Node.js 18.x+
#   - Nmap (optional, for live scans)
#   - Nuclei (optional, for live scans)
#
# LLM backends are all optional and all have a free tier. The app auto-selects
# whichever is configured (see backend/.env.example):
#   - Groq, Google Gemini, OpenRouter (free models only), NVIDIA NIM
#   - Ollama for fully offline use
# All four cloud providers are reached over plain HTTP via `requests`, so no
# vendor SDK is required for them.
#
# Quick Setup:
#   Windows:  Double-click Run_VulnDetect.bat
#   Linux/Mac: ./Run_VulnDetect.sh
#
# Manual Setup:
#   cd backend
#   python -m venv venv
#   source venv/bin/activate  # Windows: .\venv\Scripts\activate
#   pip install -r requirements.txt
#   python main.py
#
# ==========================================

# nothing. Downgrading here does not lose data, it hides it.
